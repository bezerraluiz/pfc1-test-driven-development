# Análise do Uso do Test-Driven Development para Legibilidade de Código e Redução de Erros

**Autores:** Luiz Antônio Ponciano Costa Bezerra · Anna Clara Teixeira de Medeiros

---

## Sobre o Projeto

Este projeto acadêmico analisa o impacto do **Test-Driven Development (TDD)** na qualidade do software, com foco em duas dimensões principais:

- **Legibilidade do código** — o quanto o código produzido com TDD é mais fácil de ler e manter
- **Redução de erros** — se a abordagem test-first diminui a incidência de defeitos

Para tornar a comparação concreta, o mesmo sistema foi implementado duas vezes: uma vez **com TDD** e outra **sem TDD**. O sistema escolhido é um **calculador de salário líquido**.

---

## Justificativa

O TDD é amplamente discutido na Engenharia de Software como uma prática capaz de melhorar a qualidade do produto final. Porém, a literatura apresenta resultados não totalmente consensuais:

- Revisões sistemáticas indicam evidências mais consistentes de melhora na **qualidade externa** (menos defeitos)
- Os efeitos sobre a **qualidade interna** (legibilidade, manutenibilidade) ainda são inconclusivos ou dependentes do contexto

Diante disso, este estudo busca compreender com mais precisão quando a adoção do TDD apresenta os melhores resultados, considerando fatores como contexto de aplicação, perfil dos desenvolvedores e forma de uso da prática.
